# IDP-Invoice

To build the application from parent folder run

./packaging/build.ps1

In dist/ you can see the IDP Executable version

in .env file the user supposed to configure
majorly
GEMINI_API_KEY
GEMINI_MODELS
POSTGRES_PASSWORD
Turn the Tally enabled to true
in dist/IDP-Invoice/tally_bridge
    you can find .env file where you should configure the Tally_company_name

You need a license.lic file which was generated by
    https://github.com/DileepSathya/IDP-licensing platform
